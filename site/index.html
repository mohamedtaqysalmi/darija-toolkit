Turn Arabizi into Arabic script, and say when it is unsure.

Moroccan chat text mixes Latin letters, digits like 3 and 7, Arabic script and French. I built this as a small, testable pre-processor for that text. It is rule-based, runs offline, and returns ranked alternatives when a word is ambiguous.

    02

    What works

    Most NLP tooling expects clean Standard Arabic or French. Darija typed on a phone is neither. This is what the package does about it today.

    • works Arabizi to Arabic script, with alternatives and scores for ambiguous words
    • works Chat normalizer: elongations (saaaafi), repeated letters, punctuation noise
    • works FastAPI endpoints /transliterate, /detect, /normalize and a Typer CLI
    • partial Detector for Arabizi, Darija in Arabic script, MSA, French and mixed text. It is keyword and script heuristics, not a trained model, and short messages fool it.
    • partial Fixtures are drafted by me and not yet reviewed line by line. Accuracy is only stated for that set.
    • not done No PyPI release yet. Install from the repository.

    04

    How it works

    Digraphs and chat digits are matched first, then vowels by their position in the word, then a small lexicon catches words the letter rules get wrong. Alternatives come from swapping one ambiguous slot at a time. 

    Arabizi token
   │
   ├─ in the lexicon? ───────► fixed Arabic spelling
   │
   ├─ collapse elongations     mzyaaaan → mzyaan
   ├─ match digraphs, digits   ch, kh, gh, 3, 7, 9
   ├─ choose vowels by position
   └─ expand alternatives from the ambiguous slots
         │
         ▼
   best spelling + ranked alternatives

    06

    How I built it

    Rules as data, not a model

    I wanted something that runs offline, installs in seconds and can be ported to JavaScript for this page. A fine-tuned model would do better on free text. It would also be bigger, slower to start and much harder to explain.

    One fixture file for Python and JavaScript

    Both engines are tested against the same JSON fixtures. If the port drifts from the package, a test fails before this page can disagree with the README.

    Failing cases stay in the suite

    Cases the rules get wrong are kept as strict expected failures. If a rule change fixes one by accident, the test run tells me to move it to the passing set.

    07

    Limits and roadmap

    • Short vowels are guessed. Arabizi does not carry enough information to do better without context.
    • Final ة versus ا, emphatic consonants and French loanwords are the most common misses.
    • Scores are hand-set weights for ranking, not probabilities.

    What comes next is tracked in the open issues. To review a fixture or add a failing case, start with CONTRIBUTING.md.
