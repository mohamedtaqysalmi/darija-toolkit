# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the
[Security tab](https://github.com/mohamedtaqysalmi/darija-toolkit/security) and use
"Report a vulnerability", or go straight to the
[advisory form](https://github.com/mohamedtaqysalmi/darija-toolkit/security/advisories/new).
Do not open a public issue for a security problem.

This is a solo-maintained project. I will try to acknowledge a report within a few days and
will tell you what I plan to do about it.

## Supported versions

The project is at an early stage and only the latest code on `main` is supported.
